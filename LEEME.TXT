HERRAMIENTAS Y DESCARGAS
======================

- Java: Eclipse Temurin JDK 21 LTS.
  Descargar para Windows, x64, JDK, instalador MSI:
  https://adoptium.net/temurin/releases/?version=21
  Habilitar la opcion de agregar Java al PATH durante la instalacion.
  Verificar desde una terminal nueva con: java -version

- Ensamblador: Kick Assembler (usamos v5.25).
  https://theweb.dk/KickAssembler/
  Elegir Download Kick Assembler y extraer el ZIP.
  Nuestro compile.bat espera KickAss.jar en la carpeta del proyecto.

- Emulador: VICE (usamos WinVICE 3.1 x64, emulador x64sc.exe).
  Descargas oficiales para Windows:
  https://vice-emu.sourceforge.io/#download
  Para una instalacion nueva, elegir la version Windows 64bit GTK3.
  La pagina tambien enlaza las versiones antiguas para Windows.
  Nuestro run-vice.ps1 tiene configurada esta ruta:
  D:\Juegos\Emulators\WinVICE-3.1-x64\x64sc.exe
  Si se instala en otra carpeta, ajustar $vicePath en run-vice.ps1.

- Editor: Visual Studio Code.
  https://code.visualstudio.com/Download
  Abrir la carpeta C:\Users\emi\workspace\c64\snake como proyecto.


COMPILAR Y PROBAR EN VICE
========================

1. Guarda los cambios en main.asm.

2. Abre PowerShell en C:\Users\emi\workspace\c64\snake y ejecuta:

   .\compile.bat

   Si la compilacion termina sin errores, se abre VICE o se recarga
   main.prg en la ventana existente.

3. En la pantalla de la C64, cuando aparezca READY., escribe:

   SYS 49152

   Presiona Enter. El programa actual pone el borde negro y vuelve a BASIC.

Repite estos pasos cada vez que cambies el programa.
SYS 49152 corresponde a la direccion $C000 usada en main.asm.

Si VICE estaba abierto sin el monitor remoto, cierralo una vez y vuelve
a ejecutar .\compile.bat. Las siguientes compilaciones reutilizaran la ventana.

Requisito: Java debe estar disponible en el PATH.
